Virtual Address Database

Applies db/schema.sql through the live app's own database connection — this is the reliable way to set it up or apply updates, since it can't accidentally target the wrong Supabase project the way pasting SQL into a browser-based editor can. Safe to run more than once.

Google Sheets Setup Guide

Your Google Sheet: Open Sheet
1
Open your Google Sheet → Extensions → Apps Script
Replace all code in Code.gs with the contents of google-apps-script.js provided to you.
2
Deploy → Manage Deployments → Edit → New Version → Deploy
This updates the existing deployment with the new GET+POST code so the dashboard can read leads.
3
Add your Script URL as a Vercel environment variable
Key: GOOGLE_SCRIPT_URL — already done if leads are being written to your sheet.
4
Also add your Script URL below so the dashboard can read leads directly
Paste your Google Apps Script Web App URL here (same URL you added in Vercel). If you've set a SHARED_SECRET in Code.gs, append ?key=YOUR_SECRET to the end — without it the dashboard won't be able to read leads.
